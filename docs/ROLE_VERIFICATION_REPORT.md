## 1. 原本已正常

- 線上首頁免登入，沒有測試帳號入口。
- 公開財產 390 筆，不含單價與保管人。
- 匿名不能列出借用、預借、歸還、帳號與操作紀錄的內容。
- 借用申請只會是 pending，不會直接改財產或加使用次數。
- 經辦不能改財產、不能改自己的角色、只能看到自己的帳號。
- 管理員密碼不是明文欄位。

## 2. 測試失敗

- 歸還表單沒有要求單位。
- 匿名可以建立未驗證的歸還申請。
- 確認借出把新紀錄 id 寫進 `current_loan` 會失敗。
- `staff_users` 沒有 `created_by`。
- 經辦手動開管理頁沒有 403 文案。
- 公開 Hook 仍是 404，所以沒有伺服器頻率限制，原始 API 也能建立重疊預借和第二筆 pending。
